# Club Votes

A place for a club to decide things together. Anyone can post a yes/no
question; everyone votes; the discussion happens underneath in comments.
One page: the open questions, each with its tally bar, then the question
itself when you open it.

## How it works

- **Questions** — the list on the first screen, newest first. Each row has
  the question, a ballot tally bar (Yes from the left in green, No from the
  right in red), the vote counts, the comment count, and your status ("You
  voted Yes", "Asked by you", "Tied"). Tap a row to open the question.
- **Voting** — on the question: Yes or No. One vote per person; change it
  any time by tapping the other button; tap your own choice again to take
  your vote back.
- **Comments** — a thread under each question, oldest first, with a
  composer. Ctrl/Cmd+Enter posts.
- **New question** — the filled button in the header opens a form sheet:
  a question (needed, 120 characters at most) and optional details
  (2000 at most).
- **Reporting** — every question and comment that is not yours has a
  Report link. Reporting asks first; the post is hidden for you at once
  and for everyone once three different people have reported it. Hidden
  posts are never shown. You cannot report your own post — delete it
  instead (the question's or comment's author can).
- **Guests** — visitors without a Homeroom account can read everything,
  but writing asks for an account (the server answers 401
  `account_required`).

## Running it

    npm ci --include=dev
    npm run build   # compiles Tailwind to public/tailwind.css
    node server.js  # needs DATABASE_URL

The server (Express + Postgres) keeps the schema in `questions.js`:
`questions`, `questions_votes` (one row per person per question, 0 = Yes,
1 = No), `questions_comments` and `questions_reports` (who reported what —
marked `staging:private` so staging never shares it as demo data). Tables
are created on boot; `hidden_at` columns mark moderation-hidden rows.

## Staging demo

Open a staging preview with `?demo=1`: about a dozen made-up questions
with votes and short threads, plus one question and one comment of your
own, under a line that says everything on the page is made up. The rows
are generated by `public/kit/demo.js` and written to the database once.

## Design

The look — cool paper grey neutrals, an ink-blue accent, the ballot tally
bar as the signature element — is described in `CLAUDE.md` and built from
the colour tokens in `styles/tailwind-input.css`, with the two drawn
screens in `public/index.html` and `public/screens.css`. The viewer's
Homeroom theme picks light or dark.
